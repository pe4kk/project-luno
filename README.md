# Luno

Site d'aide au travail scolaire pour le lycée : calendrier des DST, cours,
flashcards, fiches de révision, tuteur et exercices.

## Lancer le site

```bash
npm ci
```

```bash
npm run dev
```

Puis ouvrir http://localhost:3000.

L'IA est pour l'instant en mode démo : voir `lib/ai.ts`. L'état du projet et
les décisions sont tenus à jour dans `CLAUDE.md`.
